# Keyboard shortcuts

**Primary** means **⌘** on macOS and **Ctrl** on Windows and Linux.

## App

| Keys | Action |
|---|---|
| **Primary + K** | Open the command palette |
| **Primary + N** | New project |
| **Primary + O** | Open a project folder |
| **Primary + B** | Show or hide the sidebar |
| **Primary + T** | Switch between the dark and light theme |
| **Primary + ,** | Preferences |
| **Primary + Q** | Quit (Windows and Linux; on macOS use the app menu) |
| **Esc** | Close the command palette, a dialog, or the find bar |

## Running a program

| Keys | Action |
|---|---|
| **F5** | Run, or pause while running |
| **F10** | Step one instruction |
| **Shift + F10** | Step back one instruction |
| **Primary + Shift + B** | Assemble now and reset the processor |

## Editor

| Keys | Action |
|---|---|
| **Tab** / **Shift + Tab** | Indent / outdent the line or the selected lines |
| **Primary + /** | Comment or uncomment the selected lines |
| **Primary + D** | Duplicate the line |
| **Primary + Shift + K** | Delete the line |
| **Alt + ↑** / **Alt + ↓** | Move the line up or down |
| **Primary + F** | Find and replace |
| **Enter** / **F3** / **Shift + F3** | Next / previous match while finding |
| **Ctrl + Space** | Open the suggestions |
| **↑** / **↓**, **Tab** or **Enter**, **Esc** | Move in the suggestions, accept one, close them |
| **Primary + Z** / **Primary + Shift + Z** | Undo / redo |

In the processor builder's **Source (.cpu)** tab, **Primary + Enter** applies your changes.

## Command palette

- **↑ / ↓**: move through the matches.
- **Enter**: run the selected command.
- **Esc**: close the palette.
